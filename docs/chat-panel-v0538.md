# 聊天面板与记录

主面板保持「鱼应」品牌。点击对话摘要查看最近十轮；用户消息在右侧，助手在左侧。点击助手气泡上方的称呼，按 Enter 保存、Esc 取消。称呼只作为本机显示偏好，不更改品牌、唤醒词或宿主 Agent 身份。

「展开全部」读取当前选定语音聊天的宿主持久记录。关麦、重新加载插件及宿主重启后仍可读取相同聊天。切换聊天后显示所选聊天，不合并其他聊天。数据来自宿主已保存的鱼应输入及 speak / whale_voice_speak 调用，不另建录音或文字存储。

主面板右上角「＋ 新会话」会创建新的鱼应 Agent。关麦时新建会保持关麦，下次开麦接续刚创建的会话。开麦时新建会将语音切到新会话，旧语音会话的后台任务会结束，历史记录会保留。

记录按页加载，更早记录按钮继续向前读取。上翻后保留阅读位置；有新消息时显示按钮，点击回到末尾并恢复跟随。浏览器最多显示 4000 条 / 4Mi 字符，达到容量时切换显示区间，宿主原记录不删除。语音调用状态不代表用户实际听到声音。

未开麦、待机、聆听及处理中在胶囊内分别显示。未开麦使用斜杠麦克风。五根条是输入状态动画，不是音量计；仅在宿主报告输入活跃时动画。减少动态效果设置会关闭动画和松手惯性。

## 首次授权

首次加载集中列出麦克风、本地音频、设置、Edge 朗读文本传输及模型来源，一键授权后，范围内操作直接执行。设置中的授权入口用于查看范围与撤销，不再列出逐项批准按钮。旧授权记录不自动扩张到此前未授权的外部服务。操作系统权限、来源改变、真实停止失败与未知结果保留对应处理。

## 验证

- Node 测试覆盖持久分页、来源与权限校验、超过40条记录、作用域改变和过期响应。
- 官方 rc.3 宿主测试写入语音及朗读事件，销毁整个 Context，再重建并只读读取，确认没有恢复 Agent 或调用模型。
- React DOM 测试覆盖十轮分组、全记录、改名/取消/中文输入法、读到一半的新消息、稳定 DOM 和滚动位置。
- Chromium 夹具使用生产视图、样式、尺寸和拖拽代码，替换宿主视觉基础控件与传输。由 Chat panel browser regression 工作流生成截图；不是 Windows 真实音频设备验收。
