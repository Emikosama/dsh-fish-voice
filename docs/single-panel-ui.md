# 更新：0.5.13 快捷主页

本页下方记录 0.5.9 结构，已由 [0.5.13 紧凑化与静默接口](compact-ui-v0513.md) 覆盖：主页不再展示对话历史、搜索或模式菜单；近期字幕保持一行，详情默认折叠且高度封顶。

# 单一面板交互（0.5.9）

所有鲸语功能共用一个稳定的浮窗DOM根节点。主页、音频与交互设置、模型/TTS配置、桌宠占位以及首次引导只是此面板内部的视图，不调用DSH页面导航，不注册独立插件设置页，也不建立第二个覆盖层。模型来源与许可仍作为明确可查看的外部资料链接，不会自动打开。

## 尺寸与动效

主页目标宽320px，设置和引导660px，收起胶囊216px，均受可视窗口约束。内层内容测量驱动真实width/height过渡，不缩放文字或用纯淡入冒充尺寸变化。高度超出可视区域时在面板内滚动。

默认短弹簧有轻微回弹；硬朗模式更紧凑；关闭动画和系统“减少动态效果”立即应用最终尺寸。新操作可中断旧过渡，输入和按钮不等待动画。每帧都限制窗口在可视边界内，但鼠标拖动left/top即时生效，不添加移动延迟。主题颜色仍直接继承DSH。

## 下拉与移动

会话历史紧跟会话按钮，模式菜单紧跟模式按钮所在行并靠右对齐，近期聊天紧跟字幕行。它们在触发处展开，推动后续内容并改变面板高度，不再集中显示在卡片最底部。关闭菜单后焦点回到正确触发按钮。

只有鼠标拖动非交互背景会移动窗口。按钮、输入框、选项标签、滑杆、列表和滚动条不触发拖动；拖拽结束不误点。方向键、Home和End不会改变窗口位置。Tab焦点、Enter/Space按钮操作以及Escape关闭菜单/返回视图等基本键盘无障碍功能仍保留。

## 安全与生命周期

同一面板仍通过原session-maybe作用域取得真实会话身份。内部切换视图不授权开麦、不建聊天、不下载、不保存配置。原有CAS、完全停止闸、来源隔离、模型安装明确确认和隐私说明不变。

返回、切页和换源对试听执行真实取消，仍针对试听开始时的原会话。停止结果未知时不假装已关闭；较旧的取消完成也不能覆盖用户较新的导航选择。模型下载属于后台任务，关闭其视图不会取消下载。

首次配置为浮窗内非模态视图，没有会话时只显示引导，不妨碍用户直接在DSH中选择会话。用户从设置重开引导，稍后设置会返回设置；初次显示后暂不配置则返回主页。

## 验证边界

单元测试与真实DSH renderer、Gateway和Chromium fixture验证界面、尺寸、控件和安全契约。没有借此声称真实Edge服务、实际麦克风或本地模型已经验证。0.5.8已披露的依赖和后端可用性限制仍适用。
