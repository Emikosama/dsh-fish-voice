# 0.5.15：一次授权、稳定小窗与全局语音前台

## 首次一键授权

插件加载时先从 owner-only Gateway 读取授权，不需要先选中会话。
首次集中列明麦克风、本地音频、设置与语音对话、DeepSeek 文本传输、模型来源与许可；点击一次保存。暂不授权也会保存选择，不在每次启动重复弹出。

授权持久化到插件本地权限记录。旧格式只迁移已明确的普通设置许可，不凭旧字段推断麦克风或外传同意。授权本身不会开麦、播放、下载或创建会话。授权范围内后续 Agent 调用直接执行；新模型来源/许可、缺少权限、无法确认上次操作、系统权限障碍再提示。不会替操作系统点击授权，也不绕过第三方访问控制或敏感数据规则。

普通配置默认直接修改，不因旧人工值再次询问。人工操作有并发优先权：新的手动操作使旧计划失效。显式停止中断正在执行的 Agent 操作。撤销授权后阻止新调用，尝试停止音频与后台下载；停止结果未知时明确标记，不伪称设备已关闭。网络/进程调用结果不明时不自动重放。

## 基础分步配置

一键授权后只做三步：选择按住说话/自由麦 → 选择朗读方式 → 完成。设备默认使用系统选择；模型、音色、音量、热键和诊断保留在更多设置，不把大段配置堆在小浮窗。

关闭语音时也能预选模式，保存 preferredListenMode，不启动帮工。真正启用后按偏好开启自由麦；冷启动撤销仍关闭运行态音频，不因保存的偏好自动开麦。已有路径、朗读设置和按键配置保留。

## 自由麦与实验判断

默认自由麦在已授权且实际开启时，把经过现有 VAD/ASR 与有效语音过滤的内容直接投递，不再要求唤醒词。
semantic.experimentalEnabled 只有明确 true 才启用原有唤醒词/语义补充判断；旧 semantic.enabled 不代表新实验选择，模型地址等旧配置保留。

保留录音停止、权限、垃圾/重复语音过滤及提示音抑制。自由麦可能录入旁人讲话或外放，建议戴耳机；没有声称已实现 AEC 或验证真实设备回声消除。

## 高度与刷新

面板高度不超过宿主可视区域与 visualViewport 交集的 60%，小屏在面板内滚动。主页、收起、配置和设置使用稳定尺寸；状态、字幕、下载进度刷新不再按内容自然高度重新伸缩。只有用户展开最近对话、设置或收起等显式操作改变尺寸档位。最近一句缩略字幕和轻量最近对话保留，不加历史搜索大面板。

## 全局前台与边界

主人在不同 DSH 窗口看到并控制同一个语音根。切换前台窗口不转交麦克风、不新建语音根，也不重置 epoch；小窗移除「让这个窗口接管麦克风」。主人控制入口和 Agent 入口分开，后者仍验证真实 Agent、语音根与许可，不因为全局 UI 就向任意 Agent 扩权。

跨所有 DSH 会话的任意调度能力需单独核验宿主 API；本版不能把全局 UI 误写为已实现全部跨会话操作。

## 验收分层

- 离线 Node/Python：授权持久化、未知结果、人工覆盖、模式预选、默认直接语音、实验开关、取消与停止。
- 真实 DSH renderer/typed Gateway：首次无会话授权、owner admission、严格 codec、会话切换、卸载和命名空间注入。
- Chromium 合成界面：60% 高度、刷新不跳动、分步引导、单次授权、字幕、主题、窄屏及交互。
- 发布版 rc.1：离线安装与运行时合约，不等于真实桌面/设备验收。

已连接 Windows 的宿主正在被使用。仅 DSH_HOME 不会隔离 Electron userData、单实例锁和协议注册，因此未为了本次验收启动第二个宿主干扰现用安装。真实桌面干净安装、实体麦克风/扬声器、ASR 模型和当时的语音服务仍需独立验收，不用 CI 全绿代替。
