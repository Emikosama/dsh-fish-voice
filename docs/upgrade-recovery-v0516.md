# 0.5.16 升级恢复与设置滚动

## 升级后无法开麦（issue #11）

0.5.15 的旧实例退出没有返回可等待的完成结果。新实例可能在旧语音会话仍存活时尝试恢复，而这次确定的句柄冲突又被记录成永久的未知结果。停止状态也没有核查旧身份记录里的存活会话。

从本版起，同一运行进程中的后续新实例会等待旧实例的根会话清理、朗读停止和音频帮工实际退出。清理失败不会被吞掉，不会一边等待旧录音停止一边启动新帮工。已有授权保留。

首次从 0.5.15 或更早版本在同一 DSH 进程中升级时，旧实例没有可等待的退出契约。为避免旧录音/TTS 未退出就启动新音频，需要完整退出并重新打开 DSH 一次。已保存授权不会清空；不是要求重复授权。

不能安全取得句柄的存活会话不会被冒充、接管或按 ID 删除。状态会显示「旧语音会话尚未退出」，小窗提供「核查并停止」。旧根仍存在时不会报「已完整停止」，也不会自动重放开麦操作。若是旧版遗留实例一直不能退出，需要完整重启 DSH，不需要再授一次相同权限。

旧版本已经记录的 enable 暂停，仅在停止操作完成、麦克风授权关闭且所有已登记旧根都已退出后解除。音量、外部发送等其他未知结果不会因此清除。重启也不自动重放语音输入或启动旧后台任务。

## 设置页滚动

设置页的顶部栏和侧边分类固定，仅当前设置内容滚动。窄屏或短屏将分类排成固定横栏；仍遵守屏幕可用高度 60% 上限。切换分类从该内容顶部开始，不会把整个浮窗或宿主页面一起滚走。首次引导同样保留标题与「下一步」，只滚动中间内容。

## 验证界限

增加旧实例延迟退出、失败退出、同根恢复、原授权继续使用、未知结果隔离及设置滚动回归。真实 DSH Gateway 和 renderer 检验接口及界面装配，不等同于用户设备上的完整桌面升级与声学验收。Windows 真机的 0.5.15 问题保留在 [本机记录](local-acceptance-2026-11-11.md)，不把旧版本的结果改写成本版通过。
