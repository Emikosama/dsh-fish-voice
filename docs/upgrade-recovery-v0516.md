# 0.5.16 升级恢复与设置滚动

## 升级后无法开麦（issue #11）

0.5.15 的旧实例退出没有返回可等待的完成结果。新实例可能在旧语音会话仍存活时尝试恢复，而这次确定的句柄冲突又被记录成永久的未知结果。停止状态也没有核查旧身份记录里的存活会话。

从本版起，同一运行进程中的后续新实例会等待旧实例的根会话清理、朗读停止和音频帮工实际退出。清理失败不会被吞掉，不会一边等待旧录音停止一边启动新帮工。已有授权保留。

首次从 0.5.15 或更早版本在同一 DSH 进程中升级时，旧实例没有可等待的退出契约。为避免旧录音/TTS 未退出就启动新音频，需要完整退出并重新打开 DSH 一次。已保存授权不会清空；不是要求重复授权。

鱼应通过确切的宿主句柄停止自己的会话和子代理。句柄未退出或清理失败时，重复停止和热重载仍保留未确认状态，需要完整重启 DSH 才能重新开麦。

DSH 前台历史页可以将已停止的鱼应会话加载为普通会话。鱼应可以正常停止，同时保留由 DSH 持有的历史。恢复该历史需要鱼应取得新的原生写入句柄。若目标仍被 DSH 占用，可以换一个鱼应会话继续，或完整重启 DSH 后先从鱼应恢复该会话。

旧版本已经记录的 enable 暂停，在明确停止并确认鱼应已撤回麦克风权限、退出所持会话和释放收音后解除。音量、外部发送等其他未知结果会保留。重启保留已授权范围与原有历史，开启后的输入由用户重新发起。

## 设置页滚动

设置页的顶部栏和侧边分类固定，仅当前设置内容滚动。窄屏或短屏将分类排成固定横栏；仍遵守屏幕可用高度 60% 上限。切换分类从该内容顶部开始，不会把整个浮窗或宿主页面一起滚走。首次引导同样保留标题与「下一步」，只滚动中间内容。

## 验证界限

增加旧实例延迟退出、失败退出、同根恢复、原授权继续使用、未知结果隔离及设置滚动回归。真实 DSH Gateway 和 renderer 检验接口及界面装配，不等同于用户设备上的完整桌面升级与声学验收。Windows 真机的 0.5.15 问题保留在 维护者本机的验收记录中，不把旧版本的结果改写成本版通过。
