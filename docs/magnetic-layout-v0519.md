# 0.5.19：DSH 内独立浮层磁吸

鱼应保留 0.5.18 的五页设置、60% 高度、固定分类和独立滚动。

## 使用

浮窗通过 React portal 渲染到文档层，避免被宿主导航文字或 shell.overlay 的父层叠上下文盖住；普通浮窗层级为 900/901，宿主正式确认对话框仍在其上。注册、会话上下文、卸载与独立控制保持原有归属。

同时启用提供 `whaleFloatingLayout` v1 服务的鲸曈后，将鱼应拖到鲸曈左、右、上、下方的近边位置，出现提示后松开即可吸附。吸附后拖动任一窗会带着另一窗整体移动，并以整个组合限制在可见边界内。显式解除或取消拖动会解吸。两窗各自收起、展开；不会替另一窗开启或停止业务。尺寸改变后保持可用的吸附关系；空间不够时解除关系，各自限制在可见范围内。

没有兼容鲸曈、停用鲸曈、协议版本不匹配或布局服务故障时，鱼应保留独立拖动，不依赖另一插件才能使用。不会静默重试业务操作。

## 边界

- 仅同一 DSH renderer 的 CSS 浮层，不是独立 OS 窗口，切换到其他应用不会跨应用置顶。
- 原生桌面窗口能力按用户最新要求暂缓，留作后续事项；此版不修改桌面宿主。
- 共享服务只接收本窗矩形、可用边界和收起状态，回写 x/y 位置及吸附提示。没有 session、owner、语音指令、采集范围或权限数据。
- 不改当前麦克风、TTS provider、观察授权或固定接收会话。

## 验证方法

- Geometry 单测检查注册/卸载、错误版本与异常回退、任一窗带动组合、重复拖动、组合边界限制、尺寸改变、显式解吸、拖动取消、拖动中卸载、独立收起和安全位置回写。
- 真实 DSH Cordis/renderer 装配检查服务晚加载、卸载后同一鱼应控制器继续存在、不发业务指令。
- Chromium 集成使用生产鱼应 geometry 与鲸曈真实纯布局协调源码。鲸曈 peer 的业务内容和拖动适配器是合成夹具，不采集画面，也不代表鲸曈完整 UI 或 Windows 真机安装通过。
- `ui/tests/fixtures/floating-layout.mjs` 是仅供测试的精确源码副本，来源和 SHA-256 记录在同目录 README；不会打包到产品。
- 浏览器检查覆盖四向吸附、双方整体拖动、组合边界限制、取消、不够空间时解吸、双方独立收起、服务卸载，以及原有完整设置页回归。结果以对应提交的 CI 为准。
