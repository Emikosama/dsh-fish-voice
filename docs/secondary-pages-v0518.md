# 0.5.18：二级页面布局与交互

## 页面结构

- 固定顶栏：返回语音、鱼应设置、配置引导。
- 固定分类：音频、交互、模型、高级、桌宠。宽窗为左侧栏；窄窗/矮窗为一排分类。
- 当前页面固定标题和刷新按钮，只有下面的内容区滚动；保留最高 60% 视口与原有实际尺寸动效。
- 音频：说话方式、麦克风、折叠的唤醒词与提示音、独立助手音量。
- 交互：快捷键、回答速度、动画。
- 模型：朗读方式 / 模型下载 / 本地路径三个视图。首次引导提供 DeepSeek 官方朗读、本地语音模型和不发声三项。
- 高级：授权与 Agent 请求、折叠诊断、对话显示与兼容性。桌宠仍明确标为计划开发中，没有虚构功能。
- 权限与首次配置：与设置采用同一有界窗口、固定页头和底部操作、内部滚动。

## 交互修复

1. 主浮窗有不透明底色，避免当前皮肤将表面色透明化时让宿主文字穿透。仍使用宿主的浅深主题与前景色。
2. 根节点不再使用 `touch-action:none`；正文明确不参与鼠标拖动，表单和滚动条不会被背景拖拽抢走。收起胶囊仍可拖动。
3. 页面进入时只做相关只读准备。刷新会读取当前页对应的音量、性能、TTS 或模型状态。不会自动播放、下载、开启麦克风或修改配置。
4. 合并重复的读取/刷新入口。受停麦限制的编辑给出可点击的「停止语音以编辑」，实际停止仍走原接口，不自动重开。
5. 已访问页面保留尚未保存的表单草稿；隐藏的朗读下载视图不再发起计划读取。更换操作会话仍丢弃旧会话草稿。
6. 侧栏支持方向键、Home、End；返回语音后焦点回到设置按钮。切页等待试听停止确认，并以最新导航意图为准。

## 旧版真实宿主观察

在 EMIKOW 的 Windows DSH 0.2.2-rc.1、鱼应 0.5.17 上，只读点击过五个设置分类并滚动模型页：导航和鼠标滚轮可用；朗读/快捷键在开麦期间禁用属于安全限制。明确观察到背景文字穿透、模型页重复读取/刷新、当前已选「不发声」在首屏下方。未改变麦克风、provider、权限或设备设置。

真宿主主题包定义了所用背景 tokens；没有取得当前皮肤的运行时 computed styles，因此没有把穿透原因断言为“宿主缺变量”。返回主页的稳定态恢复为约 320×304，过渡中间尺寸不是故障。

- 构建与自动测试记录随最终提交核验。
