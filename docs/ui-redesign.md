# 鱼应 0.5.7 界面与能力边界

## 操作

- 完整浮窗的非交互背景可拖动，按钮、输入框、滑杆、列表和弹层保留原操作。无专用拖拽点。0.5.9 起仅鼠标拖动位置，方向键/Home/End不移动窗口；保留Tab/Enter和Esc等基础控件操作。收起不会关闭语音。
- 胶囊显示当前语音根的名称，过长省略。名称只从该来源的已验证语音目录取；读取失败时显示短根 ID，不借用前台普通聊天名称。
- v5 鲸尾是唯一状态标志。授权静态；仅接到匹配授权、epoch、序号的真实输入开始事件才呼吸，结束/取消/失权立即停止。它不表示已确认助手出声。辅助程序离线、未知状态不显示“正在听”。
- 一行字幕是当前语音根的最近助手文字，过长省略，点击打开最多 40 条近期聊天。没有“最近播报”前缀和扬声器图标。它不是播放回执，也不读取普通聊天或后台子代理回复。
- 私有字幕流使用正式 Typert Gateway、严格编解码、owner principal 和实际 Agent 身份；切换来源、换根、撤销授权、断连和卸载会清空。仅内存保存，不落盘、不发送分析事件。
- 历史在面板下拉菜单。搜索仅覆盖已载入的页；归档记录不会自动取消归档。新建/接续会切换当前语音，可能结束原语音根后台任务。

## 独立设置

音频、交互、模型、高级、桌宠分栏。音频输入、提示音、独立助手输出音量分别配置，保存不会授予麦克风权限或下载模型。

Windows 按键说话基于 WH_KEYBOARD_LL。默认未绑定；支持 F1–F24、字母、数字、Space 及 Ctrl/Alt/Shift，拒绝 Meta 和 Alt+F4。改变键盘或鼠标绑定必须完全停止且没有授权、owner 或控制任务。保存后下次明确开启生效。按键不被系统吞掉，单个可打印键可能同时输入到其他应用。详见 [键盘行为](keyboard-ptt.md)。

独立输出音量只在验证到 Windows dsh-speak 正式 live volume 配置时出现。窄字段 CAS 修改该已安装后端的 SAPI 实例音量，不证明当前语音路由正在使用它，不修改 DSTuber、系统音量或提示音。macOS 与 DSTuber 缺少已验证音量接口时明确不可用，不显示假滑杆。下一段输出生效，不保证改变已开始的声音。详见 [输出接口](voice-output-contract.md)。

三档性能设置保留兼容模式，严格档位仅在后端公布对应 effort 时可选。只允许完全停止时保存，不自动 close/reopen。活动 root 的修改请求拒绝且保留其后代；明确关闭只 drain 该 voice root，不影响独立原聊天任务树。外部提供者是否执行 effort 仍为 not_verified，TTS 常驻仍 unverified。

桌宠入口使用单色线性头像，只有“计划开发中”。TTS 后端选择和参考音频克隆尚无已验证支持时只显示能力说明，不伪装可选；不会读取、保存或上传参考音频，也不自动接入云服务。未来接入须先说明处理位置、接收方、文本与音频上传范围。

## 主题与动效

使用宿主 `--dsw-alias-*` 的背景、文字、边框、强调色和状态色，自动跟随深浅模式和强调色变化，不自建主题开关。焦点轮廓始终可见。

Q 弹为默认，另有硬朗、关闭动画。选择立即预览并保存在本地；跨窗口 storage 同步，失败时明确提示未保存。不延迟命令或拖拽。系统 `prefers-reduced-motion` 优先关闭动态。

## 验证范围

Node/Python 测试、真实 DSH renderer 装配与正式 Gateway 端到端使用合成会话/传输，不会启动用户麦克风、模型或发送文本。浏览器测试在 CI 中运行真实 Chromium，并输出明确标注“装配测试”的浅深主题、强调色、胶囊、输入状态及设置截图。测试结果须以对应提交的 CI 状态为准。

本地执行环境禁止 Chromium 所需的 socket，因此本地浏览器尝试未启动页面。不能以生成的概念稿代替运行验收。Windows 物理麦克风、全局键盘钩子和实际扬声器仍需目标机器验收；软件级测试不是声学播放证明。
