# 0.5.16 唤醒词模式

0.5.39-rc.21 的声学识别、资源准备和近音规则见[本地声学与近音唤醒](phonetic-wake.md)。

小窗的说话方式可在「按住说话」「自由麦」「唤醒词」之间切换。关麦时只保存选择；点击开麦才启动监听。唤醒词沿用已有麦克风授权，不在每次调用时重复审批。

## 使用

默认称呼是「小鲸鱼」。选择唤醒词并开麦后：

- 单说「小鲸鱼」：状态切到「正在听下一句」，等待一条指令，不向模型发送空消息。
- 说「小鲸鱼，帮我整理这段内容」：去掉称呼，发送后面的指令。
- 发送一条指令或等待超时后回到「等待唤醒词」。不会把模型回答结束当成已验证的自动续聊信号。
- 按住说话可临时接管；关麦停止监听。切换前台窗口仍控制同一个语音根。

设置 → 音频 → 唤醒词设置可以改称呼和等待秒数。需先关麦，防止界面已显示新称呼而设备还在使用旧称呼。支持 1–8 个称呼、每个 2–24 字；只匹配句首或独立称呼，不启用旧的宽泛同音词表。默认等待 10 秒，可设 3–30 秒。

## 已实现的处理方式

当前为本机 VAD 分段、ASR 转写后匹配称呼，需要等待短句识别完成。不是专用低功耗关键词引擎，不承诺系统锁屏或 DSH 退出后唤醒。时限包含识别处理时间，慢模型或较长语句可能超时。

自由麦仍直接处理有效语音，唤醒词是独立第三模式，不会重新给自由麦加唤醒门槛。唤醒词模式不依赖实验性语义判断。

状态从帮工实际状态经私有 Gateway 流更新，不用假动画或定时聊天命令模拟：未启用、启动中、等待称呼、听取下一句、暂停、错误。只有设备流已打开才显示等待或听取。状态改变不清空最近回复，也不改变浮窗尺寸。

## 隐私与中断

没有唤醒的环境语音不会进入 recent、下游提示或文本诊断。切换模式、停止、PTT 抢占和超时会使旧采集结果失效；Node 的异步投递队列在发送前再次检查采集代次，旧结果不会在下一模式迟到发送。

PTT 调试录音默认不再持久保存。仅人工明确设置 retainRecordings=true 才保留；普通 Agent 音频设置接口不允许开启该字段。已授权语音对话的消息历史与调试录音是不同数据。

仍建议使用耳机减少回声；未实现或验证 AEC。外部 TTS 文本传输遵循已有服务授权，唤醒监听本身不增加云端唤醒请求。

## 验收范围

Node/Python、真实 DSH renderer 与 typed Gateway、Chromium 合成界面覆盖控制状态和接口边界。真实麦克风、实体声学环境、ASR 模型质量和 Windows 设备唤醒尚未验证。专用本地 KWS、基于真实播放结束事件的连续对话、语音取消/结束命令留待后续单独实现，不在此版本伪装成可用功能。
