# 主界面音频设备

主界面有“音频输入”“音频输出”两个菜单。首次都使用系统默认；选择成功后自动保存。选择“系统默认”保存的是跟随系统的策略，不是当时的设备序号。

输入在关麦并确认清理完成后可切换，重新开麦使用新选择。输出在下一段播放时生效，不重播正在进行的段落。打开菜单时刷新设备列表，主面板可见时也会定期刷新。设备断开保留选择并提示，手动指定的耳机不会悄悄回落到扬声器。重连后列表恢复该选择，后续开麦/播放仍用它；录音中断不会擅自启动新的采集流。

Windows 用系统端点 ID 持久化设备，不用枚举顺序。USB 拔插及重启后按 ID 恢复；卸载或更换驱动后 ID 可能变化，此时需重新选择。Windows 输入直接打开 WinMM 端点，在开始采集前复核真实句柄，不依赖 PortAudio 的缓存序号或截断名称。旧版名称/序号输入配置继续可读，不自动覆盖；重新选择后升级为稳定标识。

Windows 上的 Edge、本地朗读和提示音都使用同一输出设备策略。只影响鱼应自身音频，不修改系统默认设备或其他应用音量。非 Windows 输入可以使用唯一的后端与设备名称身份；原生朗读仍仅支持 Windows，因此其他平台不显示虚假的可切换朗读输出能力。

系统默认使用 Windows WinMM 的默认输入/输出映射器，不把“默认通信设备”另作固定选择。默认输入在创建新的捕获流时解析当前系统默认设备，输出在创建新的播放流时解析。已经打开的输入或输出流不会凭空迁移；停止后下一次打开使用当前默认。列设备不录音、不加载识别模型，也不请求额外麦克风权限。

设备枚举成功不等于声学实测成功。自动化测试验证配置、路由参数和取消/异常边界；实际设备声音与热插拔仍需要真机验证。

切换输出设备会撤销先前“已使用耳机”的声学隔离确认，并关闭实验自动打断。旧设备的物理隔离假设不能沿用到新扬声器。提示音开关和音量不变。

旧版仅在 turnSignals.outputDevice 中配置的提示音专用覆盖仍兼容；首次用新输出菜单保存后，提示音与朗读统一使用新选择。
