# 首次配置与安装边界（0.5.8）

## 首次打开

首次打开通过 owner-only 私有只读接口取得 `{version:1,completed:false}` 时显示配置引导，没有选中会话也能查看和稍后关闭。不读取完整配置路径，不创建聊天。选中真实会话后才取得配置与停止状态。用户可稍后设置，也可从独立设置重新打开引导。

引导不会自动开麦、下载模型、联网试听或上传音频。完成按钮仅保存“已选择配置”，不表示本地模型已安装、已加载或实际声音已验证。

## 朗读

- 首次设置预选 Edge「晓伊」。点「启用在线朗读并继续」时确认向微软发送朗读文字。
- 安装包附带 Edge 短进程所用的 Node 组件。联网失败时在面板显示文字。
- Edge/系统没有 GPU 选项；本地/云端处理范围明确显示。敏感个人文本仍需单独授权，不把一般朗读同意扩展到历史、文件、录音或声纹上传。
- 试听命令没有文本参数，只允许固定公开中文样句。取消独立于全局忙状态，先中止原命令信号，再向原会话请求取消。关闭引导、切换设置分类、离开设置、换源或卸载都会终止当前试听。退出未确认时禁止再次播放；需要读回状态，后端 blocked 时需要完整重启。
- 输出音量使用配置中的独立 `ttsSetup.volume`；旧 dsh-speak 音量只控制它自己，不能代表鱼应新后端或其他语音路由。
- 声音克隆没有已验证实现。界面不提供虚假上传入口，也不读取、保存或发送用户参考音频。

## 本地模型

读取安装状态只读本地任务元数据；不会探测 Python、下载、读取权重或加载模型。硬件/运行时检测由明确按钮触发。

CPU 为默认选项。仅 Whisper 的实际 CTranslate2 CUDA 探测通过后提供 CUDA；不根据显卡品牌、内存推测已可用。模型推荐来自已披露的主机内存启发式而非实测基准。Qwen 可显示推荐理由但仍标明“暂不可安装”，没有兼容运行时就不提供可点击的安装动作。

安装前显示固定来源、具体文件、大小、SHA-256、目标目录、许可和计划哈希。用户确认才开始下载，不自动安装 Python 软件、覆盖配置或加载模型。安装任务有只读进度流；关闭 UI 不停止下载。暂停保留临时文件，取消清除此任务临时文件，重启保持暂停，不自动恢复。若命令结果未知，先读取安装状态，绝不自动重试写操作。

字节进度不等于安装或加载完成。下载与哈希校验成功后，用户仍需显式“校验并应用到配置”，且语音必须完全停止、修订号一致。应用不会热切换当前会话；重启帮工后才可能加载。

## 主题、动效与验证范围

沿用 DSH 深浅色、强调色和三档动效，系统减少动态优先。0.5.9 起首次引导是同一悬浮窗内的非模态视图，支持Tab/Enter等基础控件操作与Escape返回，不锁住宿主焦点。操作不等待动画。

离线单元与真实 DSH Gateway/renderer 测试使用合成 fixture，不连接 Edge、不下载真实模型、不证明实际麦克风、Windows 音频设备或听感已通过。后续 CI 截图也遵守此边界。

## 0.5.25：切回已安装的本地朗读

已下载并使用过本地模型后，如果改成系统语音或不发声，再在向导中选择本地模型，可用「验证并使用」重新校验并应用已有安装，不重新下载。操作携带当前配置 revision 和明确的安装任务 ID，仍需完全停止语音，遇到未知状态或其他正在等待/验证的安装意图时不能应用。

安装历史与当前配置分别显示。只有当前 provider、model ID 和已安装路径都匹配时，才显示已设为朗读来源；旧任务的成功记录不会覆盖新任务。正在下载任务原有的暂停、取消入口保持不变。

React/jsdom 回归覆盖 system/off 切回本地、应用正确任务与当前 revision、应用后继续到向导第三步、旧意图与新任务隔离，以及未知状态下拒绝应用但保留下载暂停/取消。测试不下载真实模型、不播放声音，不代替 Windows 实机验收。
