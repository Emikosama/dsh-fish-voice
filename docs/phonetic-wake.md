# 离线近音唤醒

用户只需设置唤醒词，不需要安装 Python 拼音包、调阈值或下载模型。仍由既有 ASR 输出文本后判断，**不是新的声学唤醒模型**，不会自动开启麦克风，也不会联网识别人声。

## 匹配边界

- 只匹配去掉句首空白/标点后的前缀，先尝试字面匹配，再尝试近音；同类优先更长别名。
- 全中文、至少两个字的别名支持无声调同音。两个字只接受同音；三个字及以上允许至多一个音节出现一次 z/zh、c/ch、s/sh 或 an/ang、en/eng、in/ing 差异。不能同时改变一个音节的声母和韵尾，也不能改变两个音节。
- 不做任意子串、编辑距离、插字/删字或跨标点/空格的匹配。混合文字、英文别名保持字面匹配及原英文词界。
- 每个字取默认读音，在别名前缀内部按最长优先应用词组读音覆盖；不会把多音字的所有读音任意组合。未知字和词典没有记录的罕见/方言读音仍可字面唤醒，但不保证近音唤醒。繁体单字有覆盖，**不自动繁简转换**，没有词组覆盖时繁体多音词也可能漏匹配。
- 只剥掉实际匹配前缀及紧随的空白/标点。单独唤醒仍只等待下一句话；既有超时、取消、PTT 暂停、授权失效和声纹检查不变。

例子（别名 → ASR 文本）：

- 小鲸鱼 → 小静雨（同音）、小金鱼（一次鼻音差异）、小鯨魚：接受。
- 依依 → 一一；重庆 → 虫情：接受。
- 小狮子 → 小思子：接受一次平翘舌差异。
- 小鲸鱼 → 小白兔、小金、小 金鱼、我提到小金鱼：拒绝。
- 鲸鱼 → 金鱼：拒绝，两音节不放宽鼻音。
- 重庆 → 中情：拒绝，使用重庆的 chong qing 词组读音，不把重任意当作 zhong。
- 吕吕 → 路路：拒绝，保留 ü/u 区别；小狮狮 → 小思思：拒绝，两处差异。
- emik → emiko、emikology、emik_help：拒绝。

误触限制：这是读音规则而非说话意图判别。句首真的在说“小金鱼”的普通句子也会唤醒“小鲸鱼”，依依/一一等短同音词尤其易误触。建议用较独特的三个字以上别名。上述测试只能证明文本边界，不代表真实人声召回率/误唤醒率。

## 数据来源与重建

- 上游：pypinyin 0.55.0，MIT，完整原许可证随包位于 `helper/wake_pinyin.LICENSE`。
- 官方元数据：https://pypi.org/pypi/pypinyin/0.55.0/json
- 固定 wheel：https://files.pythonhosted.org/packages/b9/7b/4cabc76fcc21c3c7d5c671d8783984d30ac9d3bb387c4ba784fca3cdfa3a/pypinyin-0.55.0-py2.py3-none-any.whl
- SHA-256：`d53b1e8ad2cdb815fb2cb604ed3123372f5a28c6f447571244aca36fc62a286f`
- 下载该 wheel 后运行 `python scripts/build_wake_pinyin.py /path/to/pypinyin-0.55.0-py2.py3-none-any.whl`。脚本先核验固定 SHA，再直接读取 JSON 和许可证，不安装或执行上游代码、不联网。普通用户无需运行。
- 提取 41,923 字的首选读音，去声调并保留 ü 为 v；提取 3,437 条不同于逐字首选读音的词组。按读音分组存字，压缩 JSON 固定 mtime=0。当前数据 259,959 字节未压缩、145,165 字节 gzip；许可证 1,105 字节。
- 运行时只使用 Python 标准库，词典首次近音判断时加载，读音结果最多缓存 128 项。数据缺失/损坏会报错，不下载、不静默伪装为支持近音。

## 验证

合成 ASR 文本测试覆盖同音、鼻音、平翘舌、多音词、误触边界、前缀剥离、等待下一句、PTT 中断旧识别。没有使用真实麦克风或语音模型；Windows 实机、真实口音和真实误唤醒率尚未验证。
