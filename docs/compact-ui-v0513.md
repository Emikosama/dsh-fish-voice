# 0.5.13：快捷小窗与静默界面接口

## 快捷主页

保留鲸鱼标识、主题色与真实尺寸弹簧动效。主页只有麦克风状态、开关、说话方式、三档回答速度，以及设置/收起。历史搜索、新建/恢复对话、列表不再挤进浮窗，开启和刷新也不再预取历史。

“按住说话”按钮是方式切换，不是屏幕录音键。点按一次切到“自由麦”，再次点按回按住说话；使用已有真实听取接口，不额外打开菜单。自由麦持续聆听的说明保留，切换仍需当前窗口已授权。

三档速度直接检查当前模型支持情况，然后用最新设置 revision 保存；语音未完全停止时保持明确提示，不偷偷关麦或重开会话。切换窗口、关闭设置或读取失败后的旧回包不能继续改设置。普通状态不显示刷新，只有读取失败/状态未知时显示重试。

用户之前要求的最近一句字幕仍保留，但仅有实际回复时占一行。点击可查看最近三条，展开高度最多160px，内容内部滚动；没有搜索或历史库。收起胶囊显示“鱼应”，不为取标题读取历史。

借鉴 NekoCapture 的快捷入口、点按切换与配置分层思想，保留自有鲸鱼图标、主题变量及代码。参考 https://github.com/NekoWs/NekoCapture/blob/main/README.md ，没有复制其 GPL 代码或图形资源。

## 为什么之前刷屏

`recordInput:false` 只禁止记录命令输入。界面调用 `remote.commands.execute('/whale-ear-ui ...')` 的成功结果仍进入宿主 `command/run`，因此每次 read-settings、status、list 都生成一条 JSON 命令消息。改输出样式或降低刷新频率无法解决来源错误。

0.5.13 所有界面读取/写入走已挂载的 typed `whaleConversation.action`，不创建命令运行记录；失败不会回退到命令通道。初始化等 Remote 就绪后才读设置与状态，焦点自动读取仍合并去重。保留手动 `/whale-ear-ui` 命令作为明确的人类命令入口，它不是界面的后台通道。

## 安全与权限

Remote 只接受 owner principal，使用宿主实时 Agent registry 校验会话对象；请求为严格白名单字段，禁止调用方声明 actor/source。内部复用同一 action dispatcher，因此原有 revision、麦克风归属、完全停止、模型下载确认、在线 TTS 数据同意与取消不确定状态保护不变。RPC 不扩大 agent 权限。会话被替换、卸载或取消后不回传旧会话数据。

完整 agent 工具覆盖属于后续独立批次，不能用 owner RPC 冒充人工授权。此版本没有新增代理越过人工设置的路径。

## 验证边界

使用真实 DSH renderer、SlotRegistry、Gateway 与严格发布包激活测试；UI fixture 的音频、模型和网络传输是合成数据，不代表用户 Windows 上真实麦克风或 TTS 已验收。CI 的 Chromium 继续覆盖明暗主题、键盘/拖动、280px 窄窗、视图打断/重复点击和取消流程。新增防刷屏与紧凑主页回归验证没有 commands.execute 回落、没有自动 list、方式单次点击切换、速度能力与 CAS/换源隔离。
