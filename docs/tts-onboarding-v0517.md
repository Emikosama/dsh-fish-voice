# 0.5.17：首次配置与本地朗读

## 怎么选择

从 0.5.39-rc.2 起，首次引导提供三项。

1. **Edge 在线朗读（默认晓伊）**。点「启用在线朗读并继续」确认朗读文字会发给微软。联网失败时显示文字。
2. **本地语音模型**。选 MeloTTS 或 Qwen3-TTS 后可下载、暂停和恢复。下载完成后无声验证合成，成功再应用。
3. **不发声**。只显示文字。

设置可以改 Edge 音色、本地模型和音量。已有 Edge、本地模型、不发声配置继续有效；旧的 Windows 系统语音和系统兜底转为文字。模型下载、朗读和录音分别使用对应的授权。

## 下载和设备

Qwen 固定公开模型与 llama.cpp b12110 CPU 运行组件，约 1.4 GiB 下载；模型来自已核实的 ModelScope 版本，运行组件来自官方 GitHub Release。Melo 使用固定的 Hugging Face 模型与 npm 官方 registry 上 sherpa-onnx-node 1.13.8 的对应平台组件。具体大小、平台、来源和许可由安装计划列出。没有承诺所有源在国内网络都可达，也没有把未验证镜像作为自动回退。

托管包当前支持 Linux/Windows x64 CPU。Qwen 固定上下文 4096，最多四个可用逻辑线程；长文按安全边界顺序分段。当前没有已验证的 GPU 运行包，因此不展示可用 CUDA，也不悄悄改设备。Windows 可能缺 VC++ 运行库，必须以实际执行检测结果为准，不能仅凭文件存在就说可用。

Qwen 的短句测试峰值约 4.60 GiB。总内存至少 8 GiB、当前可用至少 6 GiB 时推荐；总内存够但当前被占用会单独提示，不把临时忙碌误叫低配、不自动换成 Melo。该阈值是实测短句加余量，不保证长文和所有机器性能。

## 人工优先与中断

首次集中授权记录明确下载源和用途。新增运行组件来源需要补充一次授权，之后同范围调用不重复要求同意。Agent 可调用相同下载和应用接口；不能覆盖人工固定字段。主人亲自选择「下载并使用」可以替换旧朗读来源，但不会修改其他音量或 ASR 设置。

下载后的应用意图由后端保存。重启仅显示需要继续，不自动下载或应用；恢复前重新核验授权、原设置和目标。等待期间改设置、撤权、模型被替换或校验失败都会阻止自动应用，原配置保留。取消必须确认原生进程退出；未确认时保持锁定并说明需重启，不宣称已安全停止。

文件 SHA-256、归档与内部文件清单、受控路径、实际运行检测、真实合成分别校验。不会执行 npm 安装脚本，不接收用户填写的任意可执行程序路径。

## 已验证与未验证

- 已验证：云 Linux 上固定 Qwen 两句中文实际生成非静音 PCM WAV；生产 adapter 验证、取消机制及临时文件清理。
- 实测 Qwen 公开普通句 4 秒音频、约 13.36 秒 CPU 合成、4.59 GiB 峰值。另一个短句约 11.57 秒、4.60 GiB 峰值。这说明当前 CPU 不是实时流式合成。
- 已验证：本地离线 SenseVoice 将「今天下午三点开会，请记得带上笔记本」转写为同句（数字变为 3）。「鲸语」转写成同音近音「金宇」，无法仅凭 ASR 认定是发音或专名识别问题。
- 已验证：Melo 私有目录安装、原生模块解析、实际短句合成；不依赖宿主恰巧全局装了模块。
- 未验证：用户 Windows 声音设备、主观音质、品牌名实际听感、外放回声、显卡推理、长文本资源峰值和用户网络吞吐。自动化 renderer/CI 不是这些设备验收。

Qwen Base 当前不使用用户参考声音，也不宣称稳定的固定音色或声音克隆。主观选择请使用设置中的固定示例试听。

## 本批回归记录

本地最终代码：Node 518 项、Python 102 项、UI renderer 119 项、真实 Gateway 5 项及官方发布 rc.1 服务/整包 8 项通过。测试使用合成会话和公开样本，不包含用户声音设备验收。

Qwen 与 Melo 均额外完成「安装器 → 受控文件解析 → 正式 TTS 运行时 → 无声合成验证」整链。该安装步骤重放已下载并核哈希的公开文件，证明接线与目录真实可用，不等于测试用户网络。Melo 测量短句峰值约 256 MiB。CI 的 Windows、Chromium 截图与最终提交结果以对应提交的 Actions 记录为准。

CI 首轮暴露了低内存 Melo 推荐状态未列入严格传输枚举的问题，已补齐并加入高/低/临时忙碌/未知内存矩阵回归；Windows 路径断言改为比较实际规范路径，兼容 8.3 短名而不放宽模型文件验证。验证过程中可显式停止，确认退出后才显示暂停。
